# Programa de reserva de asientos de cine

Este programa está hecho en Java.

Simula una pequeña sala de cine de 3 filas y 4 columnas donde el usuario puede reservar un asiento.

Funcionamiento:
1. Se muestra el estado inicial de la sala
2. El usuario ingresa fila y columna
3. El asiento reservado se marca con X
4. Se muestra la sala actualizada

Lenguaje utilizado:
Java
